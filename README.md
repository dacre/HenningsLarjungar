# Strategier
## RenMom
RenMom, även känd som PureMom utgår från fåtal aktier hållna i kort tid där indikatorer pekar på att de kommer gå upp i värde
Mer info här: https://borslabbet.se/sammansatt-momentum/
### Dans version
Dan kör 16 aktier, minst 4 branscher, ev max 50% i en branch. Var tredje månad väljs aktierna om. 
### Stefans version
1 aktie som går till 1000% om och om igen ;)
